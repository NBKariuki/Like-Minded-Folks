💰 Like-Minded Folks - MMF Account Tracker
A clean, mobile-first web tracker for managing group Money Market Fund (MMF) contributions and balances.

🚀 Quick Start
Upload index.html and MMF_Tracker_20**_For_Website.xlsx to your GitHub Pages repository
Enable GitHub Pages in repository settings
Share the link with your group members!

✨ Features
Real-time Balance Tracking - Members check their current balance anytime
Group Statistics - Total contributions and interest earned
Member & All-Members View - Individual or comparative view
Mobile-Optimised - Works perfectly on phones
Auto-Updated Timestamp - Shows when data was last modified
Left Sidebar with:
📊 Track Contributions link
💳 Deposit instructions (M-PESA + Bank)
📜 Group rules summary
